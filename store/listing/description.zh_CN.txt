流光帮助你发现网页中的 HLS/M3U8 视频，并在本机下载、合并为 MP4。也支持手动添加 MP4 直链和解析部分 X（Twitter）视频。请仅下载自行创作或已经获得下载授权的内容。

使用方法
1. 打开视频网页并播放视频。
2. 打开流光，在「发现视频」中查看已检测到的视频源，可先预览。
3. 确认名称后点击「下载 MP4」，在「下载任务」中查看进度和保存结果。

主要功能
• 自动检测 HLS/M3U8 请求，也支持粘贴 M3U8、MP4 或 X 帖子链接。
• 多个视频独立并行下载，同时下载任务数和排队数量均不设固定上限。
• 单个 HLS 视频可设置分片并发和失败重试，支持独立音轨及普通 AES-128 分片。
• 在保存前编辑文件名或使用当前网页标题；已完成文件可在用户授权文件夹后原地改名。
• 可选择按 Chrome 下载设置自动保存，或在保存时自行选择位置。
• 关闭插件弹窗后继续处理；浏览器需要保持运行。
• 本机诊断日志可按需导出，帮助排查下载或合并问题。

本机处理与权限
为了发现当前网页的视频，流光会在本机处理网页标题、网页与媒体地址、视频元数据，以及与检测有关的媒体请求和播放事件。视频下载、解密和合并在浏览器内完成，不上传到开发者服务器，没有广告、统计或行为分析服务。

下载请求会连接视频所属网站；浏览器可能按该网站的规则附带已有身份凭据。流光不读取密码或 Cookie 值，也不要求导出 Cookie 或粘贴账号令牌。X 公开帖子解析可能请求 X 官方公开嵌入接口。文件改名只处理用户主动授权的文件夹与目标文件。

使用范围
• 仅用于你有权下载的媒体；能够观看不代表已经获得下载授权。
• 不支持 DRM、SAMPLE-AES、持续录制直播，不绕过付费墙、登录或其他访问限制。
• 本版本不提供 YouTube 下载功能；B 站 DASH 视频也不在当前支持范围内。
• 登录、地域、短时签名或站点规则可能影响可用性，不能保证任意网站或任意视频均能下载。
• MP4 合并保留原有音视频编码，不提高原片画质。
• 实际并行处理能力和可处理大小受浏览器、网络、可用内存及磁盘空间影响；重载扩展或退出 Chrome 会中断未完成任务。
