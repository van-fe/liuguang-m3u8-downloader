流光上架演示媒体

demo.mp4、sample.m3u8、sample-b.m3u8 及其 TS 分片由 FFmpeg 内置 testsrc2 / smptebars 图形和 sine 测试音生成，未使用第三方节目、影视片段或用户媒体。

本页面允许用户及 Chrome Web Store 审核人员下载这些演示媒体，以测试流光扩展的发现、预览、并行下载、保存和本地改名功能。这项许可仅涉及此演示目录，不表示对其他网站媒体拥有下载授权。

生成命令保存在相邻的 store/review/generate-demo.mjs。项目代码遵循仓库根目录 LICENSE 中说明的许可；FFmpeg 和其他第三方软件保留各自许可。
